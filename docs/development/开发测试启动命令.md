# EchoVoice 开发测试启动命令

以下命令都在仓库根目录执行（示例为 Windows PowerShell）：

```powershell
cd <仓库根目录>
```

## 0. 推荐：使用 VS Code 可见终端任务

已经提供 VS Code 任务配置：

```text
.vscode/tasks.json
```

在 VS Code 中打开命令面板：

```text
Ctrl + Shift + P
```

然后执行：

```text
Tasks: Run Task
```

推荐选择：

```text
EchoVoice: Dev Server + Web Client
```

如果要启动独立 Tauri 桌面客户端窗口，选择：

```text
EchoVoice: Tauri Desktop Client
```

如果 `go` 还没有进入 PATH，选择：

```text
EchoVoice: Dev Server + Web Client (Go fallback)
```

VS Code task 中的 fallback 已直接调用 `D:\Environment\bin\go.exe`，不使用 PowerShell 专用的 `&` 前缀，因此在 `cmd.exe` 终端下也可以运行。

开发任务不会提供客户端恢复所有者入口。需要调整服务器所有者时，请在 EV Server 终端中使用管理控制台命令，避免客户端绕过服务器管理边界。

这会在 VS Code 的集成终端中启动：

- `EchoVoice: EV Server`
- `EchoVoice: Web Client`

手动重启方式：

1. 在对应 VS Code 终端里按 `Ctrl + C` 停止任务。
2. 再次执行 `Tasks: Run Task`，选择同一个任务。

浏览器访问客户端：

```text
http://127.0.0.1:7173/
```

## 1. 启动 EV Server

打开第一个终端：

```powershell
cd services/ev-server
go run ./cmd/ev-server
```

如果当前终端还不能直接识别 `go`，使用本机 Go 路径：

```powershell
cd services/ev-server
& 'D:\Environment\bin\go.exe' run ./cmd/ev-server
```

默认服务地址：

```text
http://127.0.0.1:17878
```

健康检查：

```powershell
Invoke-WebRequest -Uri http://127.0.0.1:17878/healthz -UseBasicParsing
```

默认 SQLite 数据文件：

```text
services/ev-server/data/echovoice.db
```

EV Server 会在当前终端输出基础运行信息和管理员操作日志，例如：

```text
admin action=channel.create actor_member_id=... channel_id=... type=text name="planning"
admin action=channel.update actor_member_id=... channel_id=... type=text name="roadmap"
admin action=channel.delete actor_member_id=... channel_id=... type=text name="roadmap"
```

后端代码更新后，请在这个终端停止旧进程并重新执行启动命令。

### EV Server 管理控制台

EV Server 启动后可以直接在同一个可见终端输入管理命令：

```text
help
server
members
owner set <member-id>
member link <保留的member-id> <需要合并的member-id>
```

- `members` 会列出成员 ID、owner 状态、在线状态和已关联设备数量。
- `owner set` 可直接将指定成员设为服务器 owner，并实时广播成员变化。
- `member link` 会把新设备产生的重复成员合并到原成员，并迁移该设备的登录凭证。建议先运行 `members` 确认两个 ID。

## 2. 启动桌面客户端

打开第二个终端：

```powershell
npm run tauri:dev
```

Tauri 会自动启动或复用 Vite 开发服务器。

当前桌面前端开发地址：

```text
http://127.0.0.1:7173/
```

客户端代码更新后，请关闭旧 Tauri 窗口，并在这个终端重新执行 `npm run tauri:dev`。

## 3. 仅启动浏览器开发客户端

如果暂时不需要打开 Tauri 桌面窗口，可以只启动 Vite：

```powershell
npm run desktop:dev
```

然后在浏览器打开：

```text
http://127.0.0.1:7173/
```

## 4. 常见开发问题

如果 Tauri 窗口报动态模块加载失败，先关闭旧窗口，然后清理 Vite 缓存：

```powershell
npm run desktop:clean
npm run tauri:dev
```

如果端口 `7173` 被占用，先检查占用进程：

```powershell
netstat -ano | Select-String ':7173'
```

如果 Windows 报 `EACCES: permission denied`，说明端口可能被系统保留。可以临时换一个端口：

```powershell
$env:EV_DESKTOP_DEV_PORT = "8173"
npm run tauri:dev
```

## 5. 核心功能回归测试

以下命令会使用临时端口、临时数据库和隔离的浏览器配置，不会覆盖开发服务器数据：

```powershell
npm --prefix apps/desktop run build
npm --prefix apps/desktop run test:workspace-browser
npm --prefix apps/desktop run test:screen-share-browser
npm --prefix apps/desktop run test:desktop-popout
cd services/ev-server
go test ./...
cd ../..
cargo test
```

`test:desktop-popout` 会短暂打开真实 Tauri 主窗口和屏幕共享小窗。若当前独立客户端正在运行并锁定 `target/debug/echovoice-desktop.exe`，先关闭该客户端，再执行测试，才能保证 Cargo 编译并验证最新代码。
