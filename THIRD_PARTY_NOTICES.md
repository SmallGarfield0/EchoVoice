# Third-Party Notices

## Unicode Emoji Data

EchoVoice's generated built-in emoji catalog is derived from the Unicode Emoji
17.0 `emoji-test.txt` data file.

- Source: https://www.unicode.org/Public/emoji/latest/emoji-test.txt
- Copyright: Unicode, Inc.
- License: Unicode License v3 (`Unicode-3.0`)
- License terms: https://www.unicode.org/license.txt

The generated catalog contains Unicode characters, CLDR short names, grouping
metadata, and derived search terms. It does not include third-party emoji image
artwork or fonts.

## Pride Flag Designs

EchoVoice renders its additional pride-flag emoji as original SVG code at
runtime; no third-party image files are bundled. The following underlying flag
designs are explicitly available under CC0:

- Progress Pride Flag, designed by Daniel Quasar:
  https://progress.gay/
- Intersex Flag, designed by Morgan Carpenter:
  https://morgancarpenter.com/intersex-flag/

The remaining geometric stripe arrangements follow commonly documented
community flag specifications. Reference glossary:
https://rcsgd.sa.ucsb.edu/resources/lgbtqia-informational-resources/pride-flags-glossary
